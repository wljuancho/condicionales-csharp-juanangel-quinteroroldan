# Problema 04. Alerta de batería

**Estructura elegida:** `if` simple.

**Justificación:** la alerta solo aparece cuando la batería está por debajo del 15 %, pero el nivel actual siempre se informa.

**Ejecución:** ingresa el porcentaje actual de batería.

**Ejemplos:** `10` → alerta y nivel actual; `80` → `Nivel actual: 80 %`.
