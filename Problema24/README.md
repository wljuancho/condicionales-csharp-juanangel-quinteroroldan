# Problema 24. ¿Día hábil?

**Estructura elegida:** expresión `switch` con patrones.

**Justificación:** los días 1 a 5 y los días 6 y 7 forman grupos definidos y los demás valores son inválidos.

**Ejecución:** ingresa el día de la semana usando 1 para lunes y 7 para domingo.

**Ejemplos:** `3` → `Día hábil`; `7` → `Fin de semana`; `0` → `Día inválido`.
