## Ejecución

Desde la raíz del repositorio, ejecuta un proyecto con:

```powershell
dotnet run --project Problema01
```

Reemplaza `Problema01` por el proyecto que quieras ejecutar. Para compilar la solución completa:

```powershell
dotnet build Condicionales.slnx
```

Las carpetas `evidencias/` están preparadas para agregar las capturas de las salidas de cada ejercicio.
