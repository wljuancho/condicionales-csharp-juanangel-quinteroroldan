# Problema 14. Estado del aprendiz

**Estructura elegida:** operador condicional ternario.

**Justificación:** una sola asignación determina si la nota alcanza el umbral de aprobación.

**Ejecución:** ingresa la nota final entre 0 y 5.

**Ejemplos:** `3,5` → `Nota: 3,5 - Aprobado`; `2,9` → `Nota: 2,9 - Reprobado`.
