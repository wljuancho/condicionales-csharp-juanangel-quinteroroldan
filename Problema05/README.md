# Problema 05. El mayor de dos números

**Estructura elegida:** operador condicional ternario.

**Justificación:** permite seleccionar el mayor entre dos valores en una sola asignación, como solicita el ejercicio.

**Ejecución:** ingresa dos números enteros.

**Ejemplos:** `14` y `9` → `El mayor es 14`; `2` y `3` → `El mayor es 3`.
