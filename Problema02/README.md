# Problema 02. Tarifa de envío por peso

**Estructura elegida:** cadena `if / else if / else`.

**Justificación:** los límites ordenados separan los rangos de peso y permiten tratar los valores inválidos.

**Ejecución:** ingresa el peso del paquete en kilogramos; se calcula y muestra la tarifa.

**Ejemplos:** `0,5` → `$8.000`; `7` → `$32.000`; `25` → `$60.000`; `0` → peso inválido y tarifa `$0`.
