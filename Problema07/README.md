# Problema 07. Signo de un número

**Estructura elegida:** cadena `if / else if / else`.

**Justificación:** se deben distinguir tres casos mutuamente excluyentes: positivo, negativo y cero.

**Ejecución:** ingresa un número entero.

**Ejemplos:** `8` → `Positivo`; `-5` → `Negativo`; `0` → `Cero`.
