# Problema 12. Aprobación de crédito

**Estructura elegida:** `if / else` y operador ternario.

**Justificación:** primero se rechaza al solicitante sin empleo y solo para los demás se clasifican los ingresos.

**Ejecución:** responde si tienes empleo; si la respuesta es afirmativa, ingresa el ingreso mensual.

**Ejemplos:** sin empleo → `Crédito rechazado`; `$3.000.000` → `Crédito alto aprobado`; `$1.800.000` → `Crédito básico aprobado`.
