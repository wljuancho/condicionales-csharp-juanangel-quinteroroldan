# Problema 09. Año bisiesto

**Estructura elegida:** expresión booleana compuesta y operador ternario.

**Justificación:** la regla de divisibilidad determina una condición lógica que produce uno de dos resultados.

**Ejecución:** ingresa un año.

**Ejemplos:** `2024` → `Bisiesto`; `1900` → `No bisiesto`; `2000` → `Bisiesto`.
