# Problema 11. Semáforo inteligente

**Estructura elegida:** `switch` con enumeración.

**Justificación:** el tipo enum restringe el estado a tres valores y el `switch` asigna una instrucción clara a cada uno.

**Ejecución:** ingresa `Rojo`, `Amarillo` o `Verde`.

**Ejemplos:** `Rojo` → `Deténgase`; `Amarillo` → `Precaución, prepárese para detenerse`; `Verde` → `Avance`.
