# Problema 13. Códigos de país

**Estructura elegida:** expresión `switch`.

**Justificación:** cada código de país es un valor exacto asociado directamente con un nombre.

**Ejecución:** ingresa un código de dos letras.

**Ejemplos:** `CO` → `Colombia`; `MX` → `México`; `ZZ` → `País no registrado`.
