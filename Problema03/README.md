# Problema 03. Menú de cajero automático

**Estructura elegida:** `switch`.

**Justificación:** cada opción numérica corresponde a una acción independiente y explícita del menú.

**Ejecución:** selecciona una opción del 1 al 4; el programa muestra la acción elegida y finaliza al seleccionar salir.

**Ejemplos:** `2` → `Ha seleccionado: Retirar`; `9` → `Opción no válida`.
