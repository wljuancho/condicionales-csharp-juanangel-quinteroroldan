# Problema 06. Piedra, papel o tijera

**Estructura elegida:** cadena `if / else if / else` con condiciones compuestas.

**Justificación:** cada victoria depende de una combinación específica de dos jugadas y el resto se distingue entre empate o entrada inválida.

**Ejecución:** escribe la jugada de cada jugador: `piedra`, `papel` o `tijera`.

**Ejemplos:** `piedra`, `tijera` → `Gana el jugador 1`; `piedra`, `papel` → `Gana el jugador 2`; `papel`, `papel` → `Empate`.
