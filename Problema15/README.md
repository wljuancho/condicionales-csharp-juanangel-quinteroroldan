# Problema 15. Índice de masa corporal

**Estructura elegida:** expresión `switch` con patrones relacionales.

**Justificación:** los límites ordenados del IMC permiten asignar cada valor a una categoría sin repetir comparaciones.

**Ejecución:** ingresa el peso en kilogramos y la estatura en metros.

**Ejemplo:** peso `70`, estatura `1,75` → `IMC: 22,9 - Peso normal`.
