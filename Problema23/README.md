# Problema 23. Inicio de sesión

**Estructura elegida:** `if / else` anidado.

**Justificación:** la contraseña solo se valida si primero se reconoce el nombre de usuario.

**Ejecución:** el usuario válido es `aprendiz` y la contraseña es `Sena2026`.

**Ejemplos:** usuario desconocido → `Usuario no encontrado`; contraseña incorrecta → `Contraseña incorrecta`; credenciales correctas → `Bienvenido`.
