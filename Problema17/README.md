# Problema 17. Control de un reproductor

**Estructura elegida:** expresión `switch`.

**Justificación:** cada comando de texto reconocido corresponde a un mensaje específico y existe una opción predeterminada para comandos desconocidos.

**Ejecución:** ingresa `play`, `pause`, `stop` o `next`.

**Ejemplos:** `play` → `Reproduciendo...`; `next` → `Siguiente canción`; otro comando → `Comando no reconocido`.
