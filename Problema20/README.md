# Problema 20. Días de cada mes

**Estructura elegida:** expresión `switch` con casos agrupados.

**Justificación:** varios meses comparten la misma cantidad de días y se pueden agrupar en una sola rama.

**Ejecución:** ingresa el número del mes de 1 a 12; febrero se considera en un año no bisiesto.

**Ejemplos:** `4` → `30 días`; `2` → `28 días`; `12` → `31 días`; `13` → `Mes inválido`.
