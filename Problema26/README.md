# Problema 26. Peaje

**Estructura elegida:** expresión `switch`.

**Justificación:** cada letra de categoría representa una tarifa exacta y los códigos desconocidos generan la excepción solicitada.

**Ejecución:** ingresa `M`, `A`, `B` o `C`.

**Ejemplos:** `M` → `Categoría M - Tarifa: $0`; `A` → `Categoría A - Tarifa: $12.000`; otra letra → excepción `Categoría desconocida`.
