# Problema 18. Montaña rusa

**Estructura elegida:** expresión booleana compuesta y operador ternario.

**Justificación:** se exige alcanzar la estatura mínima y, además, tener 12 años o ir acompañado por un adulto.

**Ejecución:** ingresa estatura, edad y si va acompañada por un adulto.

**Ejemplos:** `1,50`, `13`, no acompañada → `Puede subir`; `1,45`, `10`, acompañada → `Puede subir`; `1,30`, `15`, acompañada → `No puede subir`.
