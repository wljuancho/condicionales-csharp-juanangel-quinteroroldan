# Problema 16. Ubicación de un dron

**Estructura elegida:** cadena `if / else if / else`.

**Justificación:** se verifica primero el origen y los ejes antes de distinguir los cuatro cuadrantes por los signos de X y Y.

**Ejecución:** ingresa por separado las coordenadas X e Y.

**Ejemplos:** `(3, 4)` → `Primer cuadrante`; `(-2, -7)` → `Tercer cuadrante`; `(0, 0)` → `Origen`; `(0, 5)` → `Sobre un eje`.
