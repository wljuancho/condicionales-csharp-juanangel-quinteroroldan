# Problema 21. Carrito de compras

**Estructura elegida:** operador condicional ternario.

**Justificación:** el singular se usa únicamente cuando la cantidad es exactamente uno; cualquier otro valor usa plural.

**Ejecución:** ingresa la cantidad de artículos.

**Ejemplos:** `1` → `Tienes 1 artículo en el carrito`; `3` → `Tienes 3 artículos en el carrito`; `0` → `Tienes 0 artículos en el carrito`.
