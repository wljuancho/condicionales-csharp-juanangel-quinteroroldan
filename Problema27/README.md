# Problema 27. Taquilla de cine

**Estructura elegida:** expresión `switch` sobre una tupla.

**Justificación:** el precio depende simultáneamente del día y de la condición de estudiante.

**Ejecución:** ingresa el día de la semana y si la persona es estudiante.

**Ejemplos:** martes, no → `$7.000`; jueves, sí → `$9.000`; jueves, no → `$12.000`; sábado, sí → `$15.000`.
