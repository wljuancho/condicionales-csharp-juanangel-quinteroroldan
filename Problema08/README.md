# Problema 08. Vocal o consonante

**Estructura elegida:** cadena `if / else if / else`.

**Justificación:** primero se descartan entradas que no sean una letra y luego se separan vocales y consonantes.

**Ejecución:** ingresa un carácter.

**Ejemplos:** `e` → `Es vocal`; `m` → `Es consonante`; `7` → `No es una letra`.
